# 登录页背景视频

把你的视频放在这个目录,命名为 **`login-bg.webm`** 即可自动生效,不需要改任何代码。

```
web/public/media/login-bg.webm     ← 必需,WebM(VP9 编码)
web/public/media/login-bg.jpg      ← 可选,首帧封面图
```

## 为什么需要封面图

视频从请求到能播放有几百毫秒到几秒的延迟(取决于文件大小和网速)。没有封面图时,
这段时间登录页背景是纯色块,视觉上像是"没加载出来"。`poster` 属性指定的图片会在
视频可播放之前立即显示,过渡更自然。

封面图取视频第一帧即可:

```bash
ffmpeg -i login-bg.webm -vframes 1 login-bg.jpg
```

## 制作建议

```bash
# 转 WebM(VP9),控制在 3~8MB;登录页是首屏,文件太大会明显拖慢加载
ffmpeg -i source.mp4 -c:v libvpx-vp9 -crf 34 -b:v 0 -an -vf "scale=1920:-2" login-bg.webm
```

- **`-an` 去掉音轨**:背景视频是静音自动播放的,音轨纯属浪费体积。而且浏览器
  对"带声音的自动播放"有严格限制,留着音轨反而可能导致自动播放被拦截。
- **时长 10~20 秒 + 循环**:比一个长视频更省带宽,观感上也看不出区别。
- **画面避开中间偏右区域**:登录卡片浮在那里,主体内容放那儿会被挡住。
- **本身偏暗**:代码里已经加了一层深色蒙版保证文字可读,素材本身太亮的话
  蒙版会显得很脏。

## 没有放视频会怎样

不会报错,也不会有裂图。代码里做了探测:文件不存在时自动退回原来的深蓝渐变背景。
所以这个目录留空也能正常使用。
